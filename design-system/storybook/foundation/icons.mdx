## Setup — React + Vite

### Step 1 — Add the Vite plugin

The plugin automatically serves icons in dev mode and copies only the icons your app uses into `dist/` at build time.

```ts
// vite.config.ts
import { designSystemIconsVitePlugin } from '@tuvsud/design-system/vite';
import react from '@vitejs/plugin-react';
import { defineConfig } from 'vite';

export default defineConfig({
    plugins: [react(), ...designSystemIconsVitePlugin()],
});
```

### Step 2 — Register the library once

Call this once in your app entry point (`main.tsx`):

```ts
import { registerGoogleMaterial } from '@tuvsud/design-system/react';

registerGoogleMaterial();
```

### Step 3 — Use icons

```tsx
import { TsIcon, TsIconButton } from '@tuvsud/design-system/react';

// Rounded (default)
<TsIcon name="home" size={24} />
<TsIcon name="home-fill" size={24} />        // filled variant

// Sharp
<TsIcon name="home" library="material-sharp" size={24} />

// Icon button
<TsIconButton name="settings" size={24} />
```

> **App deployed at a sub-path (e.g. `/myapp/`)?**
>
> Set `base` in `vite.config.ts` — the plugin reads it automatically. Then pass a matching `basePath` to `registerGoogleMaterial`:
>
> ```ts
> // vite.config.ts
> export default defineConfig({
>     base: '/myapp/',
>     plugins: [react(), ...designSystemIconsVitePlugin()],
> });
>
> // main.tsx
> registerGoogleMaterial({ basePath: '/myapp/icons/material-symbols' });
> ```

## Setup — Angular (esbuild, default)

No plugin needed. Angular's asset pipeline copies the SVG files for you.

### Step 1 — Add entries to `angular.json`

Inside your build target's `"assets"` array, add one entry per style you use:

```json
"assets": [
  "src/favicon.ico",
  "src/assets",
  {
    "glob": "**/*.svg",
    "input": "node_modules/@material-symbols/svg-400/rounded",
    "output": "icons/material-symbols/rounded"
  },
  {
    "glob": "**/*.svg",
    "input": "node_modules/@material-symbols/svg-400/sharp",
    "output": "icons/material-symbols/sharp"
  }
]
```

### Step 2 — Register the library once

```ts
// main.ts
import { registerGoogleMaterial } from '@tuvsud/design-system';

registerGoogleMaterial();
```

### Step 3 — Use icons

```html
<ts-icon name="home" size="24"></ts-icon> <ts-icon name="home-fill" size="24"></ts-icon>
<!-- filled variant -->
<ts-icon name="home" library="material-sharp" size="24"></ts-icon>

<ts-icon-button name="settings" size="24"></ts-icon-button>
```

> **App deployed at a sub-path?** The `output` in `angular.json` is always relative to the app root — no change needed there. Only update `registerGoogleMaterial`:
>
> ```ts
> registerGoogleMaterial({ basePath: '/myapp/icons/material-symbols' });
> ```

## Setup — Angular (webpack-based)

Used when you have `@angular-builders/custom-webpack` configured.

### Step 1 — Install the peer dependency

```bash
npm install --save-dev copy-webpack-plugin
```

### Step 2 — Add the plugin to your webpack config

```ts
// custom-webpack.config.ts
import { designSystemIconsWebpackPlugin } from '@tuvsud/design-system/webpack';

module.exports = {
    plugins: [designSystemIconsWebpackPlugin()], // copies rounded + sharp by default
};
```

### Step 3 — Register the library once

```ts
// main.ts
import { registerGoogleMaterial } from '@tuvsud/design-system';

registerGoogleMaterial();
```

## Using a different icon weight

The default package is `@material-symbols/svg-400`. If you need a different stroke weight, swap the package — the browser-facing path stays the same.

```bash
npm install @material-symbols/svg-200
```

**React + Vite** — pass `package` to the plugin:

```ts
// vite.config.ts
export default defineConfig({
    plugins: [react(), ...designSystemIconsVitePlugin({ package: '@material-symbols/svg-200' })],
});

// main.tsx — no change needed
registerGoogleMaterial();
```

**Angular esbuild** — change the `input` path in `angular.json`:

```json
{
    "glob": "**/*.svg",
    "input": "node_modules/@material-symbols/svg-200/rounded",
    "output": "icons/material-symbols/rounded"
}
```

```ts
// main.ts — no change needed
registerGoogleMaterial();
```

## Dynamic icon names

The Vite plugin detects icon names by scanning your source files at build time. **Hardcoded string names are detected automatically:**

```tsx
<TsIcon name="home" />                          // ✅ detected
<TsIcon name={"home"} />                        // ✅ detected
<TsIcon name={flag ? 'home' : 'search'} />      // ✅ detected — both values
```

**Variables, props, and runtime values cannot be detected:**

```tsx
<TsIcon name={iconName} />                      // ❌ not detected
<TsIcon name={props.icon} />                    // ❌ not detected
<TsIcon name={statusMap[status]} />             // ❌ not detected
```

For these cases, add the possible icon names manually via `additionalIcons`:

```ts
// vite.config.ts
export default defineConfig({
    plugins: [
        react(),
        ...designSystemIconsVitePlugin({
            additionalIcons: [
                { name: 'check_circle', style: 'rounded' },
                { name: 'cancel', style: 'rounded' },
                { name: 'warning', style: 'rounded' },
                { name: 'info', style: 'rounded' },
            ],
        }),
    ],
});
```

Both static detection and `additionalIcons` work together — only add the names that can't be auto-detected.

## Custom SVG — Inline (slot)

Pass any SVG directly as a child. Slotted content takes full precedence over `name` and `src`.

**React**

```tsx
<TsIcon size={32}>
    <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24">
        <path d="M12 2L2 22h20L12 2z" />
    </svg>
</TsIcon>
```

**Angular / Web Components**

```html
<ts-icon size="32">
    <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24">
        <path d="M12 2L2 22h20L12 2z" />
    </svg>
</ts-icon>
```

You can also slot an `<img>`. If the `src` ends in `.svg`, the component fetches and inlines it so `currentColor` keeps working:

```html
<ts-icon size="32">
    <img src="/assets/icons/my-icon.svg" alt="My icon" />
</ts-icon>
```

## Custom SVG — Direct URL (`src` prop)

Point the component at any public `.svg` file. No library registration required.

**React**

```tsx
<TsIcon src="/assets/icons/custom.svg" size={32} />
```

**Angular / Web Components**

```html
<ts-icon src="/assets/icons/custom.svg" size="32"></ts-icon>
```
