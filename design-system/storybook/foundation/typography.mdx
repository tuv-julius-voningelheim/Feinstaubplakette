The brand font used in our design system is **TUV SUD Pro**. It is used for all text elements including headings,
paragraphs, buttons, and labels.

---

### Loading the Fonts

The fonts are hosted on the TÜV SÜD asset CDN and are loaded automatically when you import the fonts CSS. At the entry point of your application, include one of the following:

**JavaScript / bundler (recommended):**

```js
import '@tuvsud/design-system/theme/fonts.css';
```

**HTML `<link>` tag:**

```html
<link rel="stylesheet" href="node_modules/@tuvsud/design-system/dist/theme/fonts.css" />
```

> The CSS file references fonts directly from `https://madc.tuvsud.com` — no additional font files need to be copied or hosted.

### Font Family

The primary font family used is:

```css
font-family: 'TUV SUD Pro', system-ui, sans-serif;
```
